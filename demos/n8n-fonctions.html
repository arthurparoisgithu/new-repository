Les fonctions n8nexpliquées par l'exemple

Une expression n8n, c'est du JavaScript entre doubles accolades, plus une centaine de raccourcis maison. Tout ce qui suit tourne vraiment dans cette page : les résultats affichés sont calculés, pas recopiés. Clique sur n'importe quel exemple pour le charger dans le bac à sable et le modifier.

    Anatomie d'une expression
    
    
    Une expression se lit de gauche à droite, comme une chaîne de montage. Chaque maillon reçoit le résultat du précédent et le transforme. La couleur indique le type de donnée qui circule à cet endroit.
    
    
    {{ $json.achats.pluck("montant").sum() }}
    
    
      
      
    1. {{ }} — les accolades disent à n8n « ce qui suit est du code, pas du texte ». Une seule paire pour toute l'expression.
      2. 
      
    2. $json.achats — le point de départ : le champ achats de la donnée entrante. À ce stade, on tient un tableau de trois objets.
      3. 
      
    3. .pluck("montant") — premier maillon. Il reçoit le tableau d'objets et n'en garde qu'une colonne. On tient maintenant un tableau de trois nombres.
      4. 
      
    4. .sum() — deuxième maillon. Il reçoit le tableau de nombres et l'additionne. On tient un seul nombre, et c'est le résultat final.
      5.

    Les variables intégrées
    
    
    Les fonctions transforment une valeur. Encore faut-il aller la chercher. Voilà les mots-clés qui donnent accès aux données du workflow.
    
  
    
  
    
    
    
      
    $jsonLa donnée de l'item en cours, telle qu'elle sort du nœud précédent.
    
      
    $json.champUn champ précis. Pour un nom avec espace ou tiret : $json["mon champ"].
    
      
    $('Nom du nœud')Les données d'un nœud plus haut dans le workflow, même s'il n'est pas juste avant.
    
      
    $('Nœud').item.json.xL'item correspondant de ce nœud. C'est la forme la plus utilisée.
    
      
    $('Nœud').all()Tous les items de ce nœud, sous forme de tableau.
    
      
    $input.all()Tous les items entrants. À combiner avec .pluck() et .sum().
    
      
    $nowDate et heure actuelles, déjà au format Luxon.
    
      
    $todayAujourd'hui à minuit. Pour comparer des jours sans l'heure.
    
      
    DateTimeLa bibliothèque Luxon complète, pour créer une date de toutes pièces.
    
      
    $itemIndexLe numéro de l'item en cours, à partir de 0.
    
      
    $execution.idL'identifiant de l'exécution. Utile dans les logs.
    
      
    $workflow.nameLe nom du workflow, pour signer une alerte.
    
    
    
  
    

    


    
  
    
    
    Six enchaînements qui servent tout le temps
    
    
    Les fonctions prennent leur valeur quand on les chaîne. Chacune passe son résultat à la suivante, de gauche à droite.
    
  
    
  
    
    
    
      
    Nettoyer un texte récupéré sur une page web
    
      
    Les balises sautent, les espaces parasites aussi, et la casse est normalisée d'un coup.
    
      
    {{ $json.contenu.removeTags().trim().toSentenceCase() }}
    
    
    
    
    
      
    Fabriquer un identifiant propre à partir d'un nom
    
      
    Accents retirés, espaces remplacés : de quoi nommer un fichier ou une colonne sans casser une API.
    
      
    {{ $json.entreprise.replaceSpecialChars().toSnakeCase() }}
    
    
    
    
    
      
    Calculer un total sur tous les items entrants
    
      
    On récupère tous les items, on en extrait un champ, on additionne. Trois maillons, zéro boucle.
    
      
    {{ $input.all().map(i => i.json.montant).sum() }}
    
    
    
    
    
      
    Relancer seulement les inscrits de plus de 30 jours
    
      
    À brancher dans la condition d'un nœud IF. Renvoie vrai ou faux.
    
      
    {{ !$json.inscrit.toDateTime().isInLast(30, "days") }}
    
    
    
    
    
      
    Se protéger d'un champ absent
    
      
    Sans garde-fou, un champ manquant fait planter toute l'exécution. Deux façons de l'éviter.
    
      
    {{ $json.pseudo ?? "inconnu" }}
{{ $json.client?.adresse?.ville ?? "non renseignée" }}
    
    
    
    
    
      
    Découper un gros envoi en lots de 50
    
      
    La plupart des API refusent les envois massifs. On découpe avant, on boucle ensuite.
    
      
    {{ $input.all().map(i => i.json.email).unique().chunk(50) }}

    Les pièges qui font perdre une soirée
    
    
    Ils reviennent tous, chez tout le monde, et ils ressemblent rarement à des erreurs.
    
  
    
  
    
    
    
      Un nombre qui n'en est pas un
      
    Ce qui vient d'un formulaire ou d'un webhook arrive en texte. "5" + 5 donne "55", pas 10. Passe par .toNumber() dès l'entrée.
    
    
    
    
    
      Les parenthèses de length
      
    length est une propriété, pas une fonction. .length() plante. Sur un objet, ça n'existe pas : utilise .keys().length.
    
    
    
    
    
      Les fonctions ne modifient jamais l'original
      
    .trim() renvoie une nouvelle valeur, il ne nettoie pas le champ. Il faut réassigner le résultat dans un nœud Set ou Edit Fields.
    
    
    
    
    
      Math devant, les fonctions n8n derrière
      
    Math.round(x) s'écrit avant la valeur, x.round() après. Mélanger les deux écritures est l'erreur de syntaxe la plus fréquente sur les nombres.
    
    
    
    
    
      Une date n'est pas un texte
      
    $json.date.format("dd/MM") plante tant que tu n'as pas appelé .toDateTime() avant. Et pour les mois en français, .setLocale("fr") doit venir avant .format().
    
    
    
    
    
      Le fuseau horaire
      
    n8n travaille en UTC par défaut. Une date affichée à 23h peut correspondre au lendemain. Règle le fuseau dans les paramètres du workflow avant de comparer des jours.
    
    
    
    
    
      Tester un champ qui n'existe pas
      
    $json.absent.trim() arrête l'exécution. $json.absent?.trim() ?? "" la laisse passer. Le point d'interrogation coûte un caractère et sauve un workflow.
